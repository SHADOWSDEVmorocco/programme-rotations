En-têtes à ajouter (.htaccess, après tests)

<IfModule mod_headers.c>
Header always set Strict-Transport-Security "max-age=31536000; includeSubDomains"
Header always set X-Content-Type-Options "nosniff"
Header always set X-Frame-Options "SAMEORIGIN"
Header always set Referrer-Policy "strict-origin-when-cross-origin"
Header unset X-Powered-By
</IfModule>

Et dans le thème enfant : remove_action('wp_head','wp_generator'); ainsi que le filtre équivalent pour la balise generator de WooCommerce.

Plan de recette après corrections

  • PageSpeed Insights mobile sur l'accueil, une fiche produit et une catégorie de chaque site : viser LCP < 2,5 s et une page d'accueil < 2 Mo.
  • Commande test complète (paiement à la livraison et PayPal), e-mails de confirmation compris.
  • Crawl des liens (Screaming Frog, version gratuite) : 0 lien 404, 0 lien de footer faux.
  • Google Search Console pour les deux domaines : soumettre sitemap_index.xml et vérifier la couverture.
  • Test des données structurées Product sur 3 fiches (Rich Results Test).
  • Sauvegarde complète avant toute mise à jour de PHP ou de WordPress.
