PROGRAMME DES ROTATIONS – VERSION EN LIGNE (FIREBASE)
=====================================================

Contenu du dossier
  public/                 le site (HTML, CSS, JavaScript) – rien à compiler
  public/js/firebase-config.js   <- À REMPLIR (étape 3)
  .firebaserc             <- À REMPLIR (étape 4) : ID du projet
  firebase.json           configuration de l'hébergement
  firestore.rules         règles de sécurité (accès réservé aux e-mails autorisés)
  tests/                  tests automatiques du moteur de calcul

Le site fonctionne aussi SANS Firebase (mode local : données dans le navigateur).
Pour essayer tout de suite : voir « Essai sur votre ordinateur » en bas.


ÉTAPE 1 – Créer le projet Firebase  (5 min, gratuit)
  1. https://console.firebase.google.com  →  « Créer un projet »
     (Google Analytics : inutile, vous pouvez le désactiver)
  2. Notez l'ID du projet (ex. programme-rotations-1a2b3).

ÉTAPE 2 – Activer la base de données et la connexion
  1. Menu « Build / Créer » → Firestore Database → « Créer une base de données »
     → emplacement : europe-west (ex. eur3) → mode production.
  2. Menu « Build / Créer » → Authentication → « Commencer »
     → onglet « Sign-in method » → activer « Adresse e-mail/Mot de passe ».
  3. Authentication → onglet « Users » → « Ajouter un utilisateur »
     → créez un compte (e-mail + mot de passe) pour chaque personne.
  4. Firestore Database → « Démarrer une collection » → ID : autorises
     → pour CHAQUE utilisateur, ajoutez un document dont l'ID est son e-mail
       exact (ex. chef.ops@exemple.com) avec un champ  nom = "Prénom Nom".
     Seules ces adresses pourront voir et modifier le programme.
     Pour retirer l'accès à quelqu'un : supprimez son document.

ÉTAPE 3 – Relier le site au projet
  1. Console → ⚙ Paramètres du projet → « Vos applications » → icône </> (Web)
     → nom : Rotations → « Enregistrer l'application ».
  2. Copiez l'objet  firebaseConfig = { apiKey: ..., ... }  affiché.
  3. Ouvrez  public/js/firebase-config.js  et remplacez
        export const firebaseConfig = null;
     par
        export const firebaseConfig = { ...collez ici... };
  (Ces valeurs ne sont pas secrètes : la sécurité est assurée par
   la connexion et par les règles firestore.rules.)

ÉTAPE 4 – Mettre en ligne  (sur un PC Windows, Mac ou Linux)
  1. Installez Node.js (version LTS) : https://nodejs.org
  2. Ouvrez un terminal (Windows : « Invite de commandes ») DANS ce dossier.
  3. Tapez une seule fois :
        npm install -g firebase-tools
        firebase login
  4. Ouvrez .firebaserc et remplacez REMPLACER-PAR-ID-DU-PROJET par l'ID du
     projet (étape 1). Ou tapez :   firebase use --add
  5. Mise en ligne (à refaire après chaque modification) :
        firebase deploy
  6. L'adresse du site s'affiche, par ex. :
        https://programme-rotations-1a2b3.web.app
     Le site est en HTTPS.

PREMIÈRE CONNEXION
  Le premier utilisateur qui se connecte trouve le programme des feuilles
  papier (ERJ.145, ERJ.145 - AVION 2, Beechcraft Cargo et Passagers).
  Pour reprendre les données du logiciel Windows :
  logiciel → Fichier → « Enregistrer une copie sous… » (.json)
  puis site → « Fichier & avions » → « Importer un programme ».

FONCTIONNEMENT EN LIGNE
  • Enregistrement automatique à chaque modification.
  • Plusieurs personnes peuvent travailler en même temps : les modifications
    apparaissent chez les autres en temps réel (en cas de modification
    simultanée de la même semaine, la dernière enregistrée l'emporte).
  • Coupure internet : on peut continuer, l'envoi se fait au retour du réseau
    (indicateur en haut à droite : synchronisé / en attente / hors ligne).
  • Historique : une copie est gardée à chaque session de travail
    (« Fichier & avions » → « Restaurer une sauvegarde »).

COÛT
  Le forfait gratuit « Spark » de Firebase suffit largement pour une équipe.

ESSAI SUR VOTRE ORDINATEUR (sans mise en ligne)
  Dans ce dossier :   firebase emulators:start --only hosting
  ou, si Python est installé :   python -m http.server 8080 --directory public
  puis ouvrez http://localhost:8080
  (Ouvrir directement index.html en double-cliquant ne marche pas : le
   navigateur bloque les modules JavaScript sur les fichiers locaux.)
